# MediMind AI — API

## Conventions
- Base path: `/api/v1/`
- Format: JSON in, JSON out
- Auth: Bearer JWT in `Authorization` header (added Phase 1)
- Errors: `{"error": {"code": "...", "message": "..."}}`
- Interactive docs: `http://localhost:8000/docs` (Swagger, auto-generated by FastAPI)

## Current endpoints (Phase 0)

| Method | Path | Purpose | Auth required |
|---|---|---|---|
| GET | `/` | Root status message | No |
| GET | `/api/v1/health` | API liveness check | No |
| GET | `/api/v1/health/db` | API + DB connectivity check | No |

More endpoints are added and documented here starting Phase 1.
